# typescript/path-traversal: Filesystem path built from untrusted input

| Field | Value |
|---|---|
| Applies to | `**/*.ts`, `**/*.js`, `**/*.mjs`, `**/*.cjs` |
| Category | SECURITY |
| Severity | HIGH |
| Confidence | MEDIUM |
| Detection type | hybrid |
| Source | node-review: Security; node-bug-hunter: Shared state, resources, and security boundaries |

## Intent
Joining request values into a path allows `../` traversal, encoded variants and symlink escapes to read or write outside the intended directory. Validation must happen after decoding and normalization.

## Detect
`fs.*`, `createReadStream`, `res.sendFile/download`, `path.join/resolve` feeding those calls, with an argument derived from `req.*`, message fields or user filenames, and no `path.resolve(...).startsWith(base + sep)`/`realpath` check or `path.basename` use.

## Do not flag
- Names generated by the server (uuid), values reduced with `path.basename`, `sendFile` with `root` option and no dotfiles.
- Checks performed after resolve and realpath.

## Examples
Flag:
```ts
res.sendFile(path.join(UPLOADS, req.params.name));
```
OK:
```ts
const p = path.resolve(UPLOADS, name); if (!p.startsWith(UPLOADS + path.sep)) throw new Error('bad path');
```

## Implementation notes
Anchor to the filesystem call.

Detected on `fs.*` read/write/remove calls and `sendFile`/`download`, when the first argument is not a literal and is derived from `req`, `request`, `params` or `message` (through a variable, one step), or is named like a file or path and is a parameter of the enclosing function. A function that mentions `basename`, `startsWith(`, `realpath`, `relative(`, `isSubPath`, `isPathInside` or a `root:` option is skipped as a whole.

## Required tests
Joined request value (finding), `basename` (no finding), resolve + startsWith guard (no finding), `sendFile` with `root` (no finding).

## AI prompt
"Is the value attacker-controlled, and does a check after decoding/normalization/symlink resolution confine it to the base directory?" Evidence: call, origin, any checks and their order.

## Why hybrid
Sinks are syntactic; check adequacy and taint need flow analysis.
